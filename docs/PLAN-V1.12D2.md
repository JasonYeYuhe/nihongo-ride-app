## 0. 不做生图(结论先行)

Jason 允许用图像生成(Claude/Codex 任一)。**决定:不用。** 理由:

1. 场景是 185 行 Canvas 纯代码绘制;`scripts/check_scene_contrast.py` 这道闸量的就是
   调色板驱动的像素。位图一进来,对比度就不再是 8 个可枚举值的函数,闸退化成"只能看"。
2. ImageRenderer 截图可复现性刚修好(冻结相位);位图资源再引入加载/缩放变量。
3. 全 app 至今零美术资源包(词库 JSON 除外),8 张全屏位图 ×2 平台 ×@2x/@3x 是兆级
   体积换一个代码能免费做的效果。
4. 风格:几何扁平风和 AI 生成位图的质感混排,违和感大于收益。

## §6 Codex 审阅结论(2026-07-19)与修订

Codex 拒绝原案,5 条 blocking,全部采纳:

1. **lane/roadFar 必须给出精确值**("~55%"不可审阅)→ §1 表格作废,以代码内数值为准;
   路色距离改用**线性分量欧氏距离**,阈值 0.12,经计算 8 段相邻全部 ≥0.146(0→1 也过,
   无需豁免)。
2. **结算屏冻结需要显式 API**——`landmarkPhase: 3.99` 只冻结地标,云和车道线照跑
   → `RideBackgroundView` 加 `still: Bool` 参数。
3. **变形结算是独立的 `ConjugationResultsView`** → 抽共享 `RideArrivalBackdrop`,两个
   结算 view 都用。
4. **裸文字 + 遮罩到不了 7:1**(太阳后 2–3:1;`Theme.dim` 45% 白在纯黑上都不够 7:1)
   → 采用与骑行屏同一原理:**结算内容坐在 0.85 黑面板上**(卡片承担对比度,场景保持
   鲜明)。度量:复用 bare 帧(其遮罩比结算的浅 ⇒ 结论保守安全),脚本加 `--box/--alpha`
   参数量面板矩形。
5. **「到站于 X」语义歧义**(rideStage 是开局冻结的,跨界时可能不是当前终身位置)
   → 文案改为对刚骑完的这程为真:「本程路段:箱根」/ "This ride: the Hakone stretch"。

另采纳:结算 8 段 ×2 变体全渲、更新 RideBackgroundView 陈旧头注释、iPhone 实机门留给
Jason(headless 验不了滚动/焦点/大字)。
