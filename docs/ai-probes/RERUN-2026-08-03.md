# Re-run of every probe, macOS 26.6 (2026-08-03)

The v1.15 probe README says to re-run these before extending any AI surface, because the
model ships with the OS and will drift. It drifted. Every capability measured WORSE than on
26.5, including the one the v1.15 plan was prepared to build on.

## Probe 2 — authoring Japanese: still 5/5 defective, with a new failure mode

| target | v1.15 (26.5) | now (26.6) |
|---|---|---|
| 勉強する | echoed the word | 「テスト勉強する.」 — ASCII period, still not a sentence |
| (garbage) | invented a sentence | invented one with doubled spaces; kana あさがつ for 朝が |
| 披露 | kana kept 出す in kanji | not a sentence at all: 「披露する」 + an English grammar note |
| 落ち着く | 落ち着いて → てきじゅうていて | 疲れた → **つらい**; 落ち着く・時間・必要 left in KANJI in the kana field |
| しかし | kana kept 面白かった in kanji | **kana field contains ROMAJI**: 「しかし、watashi wa ima, benkyo wo shiteimasu.」 |

Romaji inside the kana field is new. Kana is the string the learner is graded against.

## Probe 4 — constrained classification: 2/4 → **1/4**

Three different inputs (kunrei, sokuon, small-ya) all came back `kunreiRomaji`. The advice
was nonsense even when the label was right: for a romaji-system problem it suggested
"Practice reading kanji characters before writing them."

This kills the "optional phrasing layer" the v1.15 plan kept in reserve. Not deferred —
abandoned. The app's own diagnosis is correct and instant; the model's is wrong three times
in four and its prose is actively misleading.

## Probe 3 — grounded explanation: was the ONE usable task, now unusable

- v1.15: "When you make a public announcement about a project or your work, you would use
  the word 披露." — usable, grounded, invented nothing.
- Now: `usage` and `hook` came back as the **identical string**, and it **authored Japanese
  despite being told not to**: 「この商品は披露します」 — which wants を, not は.

Latency also regressed (1–2 s warm → 2–8 s).

## What this means for v1.16

There is no on-device AI surface worth building right now. Not "not yet" — the three
capabilities that would carry one all moved the wrong way in a single OS point release, and
the only one that used to work now fabricates incorrect Japanese in a task whose entire
premise was that it would not have to produce any.

The constraint from v1.15 §2 therefore hardens rather than relaxes, and the AI in v1.16 is
the AI that has already been MEASURED to work: a large model, offline, in the content
pipeline, behind deterministic gates and a human read. That shipped 779 sentences in v1.15
and it is the right place to spend the next batch.
