## Gates — read this before believing a red

`bash scripts/run_all_gates.sh` (floor now **12**, `--headless` 11): **12 run · 9 passed · 1 no
coverage (store gates, exit 3) · 1 vacuous · 1 FAILED — `swift test`**. The failure is
environmental and new since macOS 27: `~/Documents` is under iCloud Drive File Provider, which
stamps `com.apple.FinderInfo` + `com.apple.fileprovider.fpfs#P` on every freshly built `.xctest`
bundle in `.build`, and codesign refuses them ("resource fork, Finder information, or similar
detritus not allowed"). Clearing the attributes does not hold — they come back on the next build.
**The same suite outside the synced folder passes:**
`swift test --scratch-path "$HOME/Library/Caches/NihongoRide-swifttest-outside-icloud"` → exit 0,
**796 tests / 125 suites** (766 / 120 at `43d0da7`). The runner was not changed to hide this; moving the repo out of
`~/Documents`, excluding it from sync, or pointing the gate's `swift test` at an outside scratch
path is the owner's call. **It will very likely hit release archive builds too** (they also build
under `~/Documents/typing_app/build`), so check before the next release.
